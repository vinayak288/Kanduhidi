**KANDUHIDI** is an exciting and interactive guessing game designed to bring fun, entertainment, and friendly competition among players. The game offers two main categories: Number Guessing and Word Guessing, allowing players to test their logical thinking, vocabulary, creativity, and guessing skills.

KANDUHIDI supports both Solo Mode and Multiplayer Mode. In Solo Mode, players can enjoy the game independently, where the system automatically generates a random number or word. Players must guess the correct answer using hints and feedback provided by the game. Their points depend on their accuracy, number of attempts, and speed.

In Multiplayer Mode, players can create their own rooms or join existing rooms using a unique room code. Two or more players can participate in the same room and compete against each other. The room creator acts as the host and can customize game settings, select game categories, choose difficulty levels, and configure time limits and scoring rules.

Each player gets an individual guessing interface where they can enter and submit their answers. The game provides real-time feedback, updates scores, and displays a live leaderboard so players can track their performance. Every room maintains its own players, game settings, scores, rounds, and progress, ensuring that changes in one room do not affect another.

KANDUHIDI also includes a rewarding points system that encourages players to guess correctly with fewer attempts and within the given time. Players can compete across multiple rounds, improve their rankings, and challenge their friends.

With its simple interface, interactive gameplay, room-based multiplayer experience, and competitive scoring system, **KANDUHIDI makes guessing more exciting, engaging, and enjoyable for everyone, whether playing alone or with friends.**
